# নোড চালানো

এই গাইডটি সেই ব্যক্তির জন্য যে তাদের ল্যাপটপে মুক্তো মেশ চালায় — **নোড অপারেটর**। আপনি আপনার কমিউনিটির হাব।

**ইন্টারনেট থাকা অবস্থায়ই এটি করুন।** সংকট আসার আগেই সবকিছু ডাউনলোড করে নিন।

## ডাউনলোড

১. মুক্তো মেশ GitHub রিলিজ পৃষ্ঠায় যান।
২. আপনার অপারেটিং সিস্টেমের (Windows, macOS, বা Linux) জন্য সর্বশেষ রিলিজ প্যাকেজ ডাউনলোড করুন।
৩. জিপ ফাইলটি আপনার ল্যাপটপের একটি ফোল্ডারে এক্সট্র্যাক্ট করুন।

## নোড শুরু করা

### Windows
`start.bat` ফাইলটিতে ডাবল-ক্লিক করুন। একটি টার্মিনাল উইন্ডো খুলবে এবং সার্ভার শুরু হবে।

### macOS / Linux
এক্সট্র্যাক্ট করা ফোল্ডারে টার্মিনাল খুলুন এবং চালান:
```
npm start
```

### চালু আছে কিনা যাচাই
আপনার ল্যাপটপে ব্রাউজার খুলে `http://localhost:3000` এ যান। মুক্তো মেশ ড্যাশবোর্ড দেখা যাবে।

## কমিউনিটির সাথে শেয়ার করা

১. আপনার ল্যাপটপকে WiFi হটস্পট করুন:
   - **Windows 10/11:** Settings → Network & Internet → Mobile Hotspot → চালু করুন
   - **macOS:** System Settings → General → Sharing → Internet Sharing
   - **Linux:** আপনার ডিস্ট্রিবিউশনের হটস্পট ফিচার বা `create_ap` ব্যবহার করুন
২. আপনার প্রতিবেশীদের আপনার হটস্পটে সংযোগ দিতে বলুন এবং ব্রাউজার খুলতে বলুন।
৩. তারা স্বয়ংক্রিয়ভাবে মুক্তো মেশ দেখতে পাবে। তাদের ডিভাইসে কোনো ইনস্টলেশনের প্রয়োজন নেই।

> **টিপ:** হটস্পটের নাম এবং নোড ঠিকানা (যেমন `http://192.168.137.1:3000`) একটি কাগজে লিখে সাধারণ এলাকায় টাঙিয়ে দিন।

## অ্যাডমিন প্যানেল

নোড অপারেটর হিসেবে আপনার অ্যাডমিন অ্যাক্সেস আছে:

১. **ড্যাশবোর্ড** → অ্যাডমিন ব্যাজ ট্যাপ করুন।
২. অ্যাডমিন পাসওয়ার্ড দিন (আপনার কনফিগারে সেট করা)।
৩. অ্যাডমিন প্যানেল থেকে আপনি:
   - সংযুক্ত ব্যবহারকারী এবং চেক-ইন স্ট্যাটাস দেখতে পারেন
   - নোটিশবোর্ড পোস্ট ম্যানেজ করতে পারেন (পিন, ডিলিট)
   - নিখোঁজ ব্যক্তির স্ট্যাটাস আপডেট করতে পারেন
   - সব ব্যবহারকারীর কাছে জরুরি সম্প্রচার পাঠাতে পারেন
   - ডেটা সিঙ্ক স্ট্যাটাস মনিটর করতে পারেন
   - প্রয়োজন হলে চ্যাট ইতিহাস মুছতে পারেন

## নোড চালু রাখা

- ল্যাপটপ চার্জে লাগিয়ে রাখুন।
- টার্মিনাল উইন্ডো বন্ধ করবেন না।
- ল্যাপটপ ঘুমিয়ে গেলে নোড বন্ধ হয়ে যাবে। স্লিপ মোড বন্ধ করুন।
- অ্যাপটি ৫-১০০ কনকারেন্ট ইউজারের জন্য ডিজাইন করা।

## সমস্যা সমাধান

| সমস্যা | সমাধান |
|---|---|
| ফোনে অ্যাপ লোড হয় না | হটস্পট চালু আছে কিনা এবং ফোন একই WiFi নেটওয়ার্কে আছে কিনা যাচাই করুন |
| পোর্ট কনফ্লিক্ট | কনফিগারে পোর্ট পরিবর্তন করে পুনরায় চালু করুন |
| নোড ধীরে চলে | সংযুক্ত ডিভাইস সংখ্যা কমান বা অন্যান্য অ্যাপ বন্ধ করুন |
| অ্যাডমিন প্যানেল খুঁজে পাচ্ছেন না | ড্যাশবোর্ডে গিয়ে অ্যাডমিন ব্যাজ ট্যাপ করতে হবে |
| পুনরায় চালু করতে হবে | `start.bat` আবার চালান — সব ডেটা ডাটাবেসে সংরক্ষিত |
