# সংকট মোকাবিলার তালিকা

**এখনই** এই তালিকাটি সম্পন্ন করুন যখন আপনার ইন্টারনেট এবং বিদ্যুৎ আছে। প্রতিটি আইটেম সম্পন্ন হলে টিক দিন।

## টিয়ার ১: ডিজিটাল প্রস্তুতি

- [ ] গিটহাব রিলিজ থেকে মুক্তো মেশ ডাউনলোড করুন এবং ইনস্টলার ল্যাপটপ ও USB ড্রাইভে সংরক্ষণ করুন
- [ ] `start.bat` চালু হয় এবং `http://localhost:3000` এ ড্যাশবোর্ড লোড হয় কিনা পরীক্ষা করুন
- [ ] তথ্য পৃষ্ঠা থেকে জরুরি যোগাযোগ ফোনে সেভ করুন
- [ ] আপনার শহরের অফলাইন ম্যাপ ফোনে সেভ করুন (গুগল ম্যাপ অফলাইন বা অর্গানিক ম্যাপস)
- [ ] গুরুত্বপূর্ণ ডকুমেন্টের (এনআইডি, পাসপোর্ট, মেডিকেল রেকর্ড) ছবি ফোনে রাখুন
- [ ] এই অ্যাপ থেকে ক্রাইসিস চেকলিস্ট এবং জরুরি যোগাযোগ প্রিন্ট করুন — ব্যাগে রাখুন
- [ ] ব্যাকআপ হিসেবে ফোনে মেশ মেসেঞ্জার অ্যাপ (Briar, Bridgefy, বা BitChat) ইনস্টল করুন
- [ ] প্রয়োজনের আগেই ফোন এবং ল্যাপটপে ভিপিএন সেট আপ করুন
- [ ] কমপক্ষে ৩ প্রতিবেশীর সাথে মুক্তো মেশ শেয়ার করুন এবং কে নোড চালাবে তা ঠিক করুন
- [ ] সব ডিভাইস সম্পূর্ণ চার্জ করুন। পাওয়ার ব্যাংক চার্জ রাখুন।

## টিয়ার ২: ফিজিক্যাল ৭২-ঘণ্টার কিট

### পানি এবং খাবার
- [ ] প্রতি ব্যক্তি প্রতি দিন ৩ লিটার পানীয় পানি (সর্বনিম্ন)
- [ ] ৩ দিনের নন-পেরিশেবল খাবার (শুকনো বিস্কুট, টিনজাত খাবার, শুকনো ফল, বাদাম)
- [ ] পানি বিশুদ্ধকরণ ট্যাবলেট বা পোর্টেবল ফিল্টার

### প্রাথমিক চিকিৎসা এবং স্বাস্থ্য
- [ ] প্রাথমিক চিকিৎসা কিট (প্রাথমিক চিকিৎসা বিভাগে তালিকা দেখুন)
- [ ] প্রয়োজনীয় ওষুধের ৭ দিনের সরবরাহ (ব্লাড প্রেসার, ডায়াবেটিস, অ্যাজমা ইত্যাদি)
- [ ] ব্যথানাশক, অ্যান্টাসিড, ওরাল রিহাইড্রেশন সল্ট
- [ ] স্যানিটারি প্যাড এবং হাইজিন পণ্য
- [ ] মাস্ক (N95 বা সার্জিক্যাল)

### সরঞ্জাম এবং সামগ্রী
- [ ] টর্চলাইট সাথে অতিরিক্ত ব্যাটারি
- [ ] পাওয়ার ব্যাংক (সম্পূর্ণ চার্জড) সাথে চার্জিং কেবল
- [ ] ছোট নোটে নগদ টাকা (৭ দিনের মতো)
- [ ] ওয়াটারপ্রুফ কন্টেইনারে ম্যাচ বা লাইটার
- [ ] মাল্টি-টুল বা সুইস নাইফ
- [ ] হুইসেল (সাহায্যের জন্য সংকেত)
- [ ] প্লাস্টিক ব্যাগ (বর্জ্য, ওয়াটারপ্রুফিং)
- [ ] নোটবুক এবং কলম
- [ ] ব্যাটারিচালিত বা হ্যান্ড-ক্র্যাঙ্ক রেডিও

## টিয়ার ৩: যোগাযোগ পরিকল্পনা

- [ ] হাঁটার দূরত্বে একটি প্রাথমিক মিটিং পয়েন্ট ঠিক করুন
- [ ] আপনার পাড়ার বাইরে একটি মাধ্যমিক মিটিং পয়েন্ট ঠিক করুন
- [ ] একজন আউট-অফ-এরিয়া কন্টাক্ট নির্ধারণ করুন যাকে ইন্টারনেট ফিরলে সবাই কল করবে
- [ ] কমপক্ষে ২ প্রতিবেশীর সাথে ফোন নম্বর শেয়ার করুন
- [ ] কে মুক্তো মেশ নোড চালাবে তা ঠিক করুন
- [ ] জরুরি সংকেত ঠিক করুন (যেমন, ৩ নক = নিরাপদ, ১ নক = বিপদ)

## টিয়ার ৪: শাটডাউনের সময়

- [ ] শান্ত থাকুন। আতঙ্কিত হবেন না।
- [ ] মুক্তো মেশ নোড শুরু করুন এবং হটস্পট শেয়ার করুন
- [ ] সাধারণ এলাকায় নোড ঠিকানা এবং হটস্পট নাম পোস্ট করুন
- [ ] অ্যাপে চেক-ইন করুন যাতে অন্যরা জানে আপনি নিরাপদ
- [ ] ফোনের ব্যাটারি সংরক্ষণ করুন — ব্যাকগ্রাউন্ড ডেটা বন্ধ করুন, ব্রাইটনেস কমান
- [ ] শেয়ার করার আগে সব তথ্য যাচাই করুন। নিশ্চিত না হলে চ্যাটে জিজ্ঞাসা করুন
- [ ] বয়স্ক বা প্রতিবন্ধী প্রতিবেশীদের খোঁজ নিন যারা অ্যাপে নাও থাকতে পারে
- [ ] শিশুদের ভয় না দিয়ে অবহিত রাখুন — তাদের ছোট কাজ দিন
- [ ] পাবলিক সোশ্যাল মিডিয়ায় আপনার অবস্থান শেয়ার করবেন না

## টিয়ার ৫: সংকটের পর

- [ ] আপনার ইমার্জেন্সি কিট পুনরায় পূরণ করুন
- [ ] আপনার জরুরি যোগাযোগ তালিকা আপডেট করুন
- [ ] মুক্তো মেশ অ্যাপ সর্বশেষ ভার্সনে আপডেট করুন
- [ ] কী কাজ করেছে এবং কী করেনি তা পর্যালোচনা করুন। আপনার পরিকল্পনা আপডেট করুন।
- [ ] অন্য কাউকে প্রস্তুত হতে সাহায্য করুন
